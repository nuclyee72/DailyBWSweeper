# 흑백 지뢰찾기 (DailyBWSweeper)

검·흰 두 가지 지뢰를 따로 세는 지뢰찾기에, 판 바깥의 검·흰 레이저를 거울로 꺾어
**같은 색 특수 칸**에 맞히는 퍼즐을 얹은 데일리 게임.

- 사이트: https://nuclyee72.github.io/ProjectDaily/DailyBWSweeper/ (ProjectDaily 허브에 서브모듈로 들어간다)
- 모드: 스탠다드 12×12 · 레이저 3 · 지뢰 24 / 익스텐디드 16×16 · 레이저 5 · 지뢰 38

## 규칙 요약

- 칸의 검 삼각형 숫자 = 주변 검 지뢰 수, 흰 삼각형 숫자 = 주변 흰 지뢰 수 (삼각형 방향은 칸마다 다름)
- 특수 칸은 숫자에서 검·흰 양쪽에 1씩 센다. 눌러도 터지지 않는다.
- 연 칸은 거울이 될 수 있다: 레이저가 반대 색 삼각형으로 들어가면 튕기고, 같은 색이면 지나간다.
- 회색 빈칸 중 일부는 색 반전기 — 늘 켜져 있고, 지나가는 레이저의 색을 바꾼다.
- 레이저가 같은 색 지뢰나 반대 색 특수 칸에 닿으면 폭발. 같은 색 특수 칸은 지나가며 명중(열어야 보임).
- 모든 특수 칸을 열고, 모두 같은 색 레이저가 닿아 있으면 클리어.

## 구조

```
index.html · style.css
src/
├─ core/board.js      판 모델 · 레이저 추적 · 판 생성(풀이 검증, 반전기 필수 보장)
├─ core/random.js     시드 난수 — 같은 날짜면 누구에게나 같은 판
├─ game/puzzle.js     모드 정의 · 시드로 판 만들기
├─ daily/             날짜(KST 06:00 경계) · 진행/통계 저장 · 공유 문구
├─ ui/                판 그리기 · 표시 팔레트 · 터치 확대/이동
├─ hub.js · hubApi.js ProjectDaily 허브 연결 (다른 게임과 같은 방식)
└─ main.js            화면 · 입력
```

데일리 퍼즐은 파일로 미리 만들지 않고, 날짜를 시드로 브라우저에서 만든다 (크론 없음).

## 로컬 실행

```
npm run dev   # http://localhost:5174
```
